## Library

- New **Filters** button in every library: filter by genre, decade, age rating, score and quality (4K, or HD or better), one category at a time. Choices are saved per library and show as removable chips above the grid. Several genres or ratings match any of them. Quality is hidden in show libraries.

## Fixes

- Tapping Search again clears the search and returns to the main search page, also from "Request it".
- The whole dashed "Add account" box is tappable.

This is an unsigned build. Install `BloomsPlayer-2.1.0.ipa` with SideStore or LiveContainer, which sign it on your device.
